═══════════════════════════════════════════════════════════
PASO 1: IMPORTAR EL WORKFLOW EN N8N
═══════════════════════════════════════════════════════════

1. Abre el archivo:
   📄 docs/n8n-workflow-export.json

2. Copia TODO el contenido (Cmd+A, Cmd+C)

3. Ve a: https://profitops.app.n8n.cloud

4. Click: "Add workflow" → "Import from File"

5. Pega el contenido o selecciona el archivo

6. Click: "Import"

✅ ¡Workflow importado con 27 nodos!


═══════════════════════════════════════════════════════════
PASO 2: ACTIVAR EL WORKFLOW
═══════════════════════════════════════════════════════════

1. En n8n, busca el toggle "Active" (esquina superior derecha)

2. Click para activarlo

3. Debe quedar en VERDE ✅

✅ ¡Workflow activado y listo para recibir requests!

PASO 4: INTEGRAR CON FRONTEND (OPCIONAL)
═══════════════════════════════════════════════════════════

1. Copia el servicio TypeScript:

   cp src/lib/pipedrive-update-service.ts /ruta/a/tu/proyecto/src/lib/

2. Importa en tu código:

   import { PipedriveUpdateService } from '@/lib/pipedrive-update-service';

3. Úsalo:

   await PipedriveUpdateService.updateMRR("Datatechnic México", 40000);
   await PipedriveUpdateService.updateStage("Datatechnic México", 4);

TROUBLESHOOTING RÁPIDO
═══════════════════════════════════════════════════════════

❌ Error: "Deal no encontrado"
   → Verifica el nombre exacto en Pipedrive
   → Respeta mayúsculas/minúsculas

❌ Error: HTTP 401 Unauthorized
   → Verifica el API token de Pipedrive en los nodos HTTP Request

❌ Workflow no responde
   → Verifica que esté ACTIVADO (toggle verde)
   → Revisa logs en n8n → Executions

❌ Actividad no se crea
   → Usa solo tipos válidos: call, meeting, task, email, deadline, lunch
